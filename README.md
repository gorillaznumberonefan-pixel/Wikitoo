# Wikitoo

Wikitoo is a public wiki project with a cleaner structure, peer review workflow, editor permissions, and PWA support.

## Quick start

1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Build for production:
   npm run build

## Project goals

- public wiki browsing
- editor request flow
- admin-managed permissions
- two-reviewer approval before publication
- searchable, topic-based article discovery
- installable offline-friendly PWA interface

## Notes

This is the frontend scaffold for the upgraded app. You can connect it to Supabase and add a real database later.
